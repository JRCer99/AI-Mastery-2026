# Month 02: Math & Stats for AI

**Focus:** Building mathematical intuition for AI — distributions, probability, statistics, and visualization from scratch.

---

## 🎯 Learning Goals

- Understand descriptive vs inferential statistics
- Visualize data distributions and spot patterns
- Implement gradient descent manually (no libraries)
- Apply Bayesian reasoning to real problems
- Connect math concepts directly to ML algorithms

---

## 📅 Projects

- [x] Project 1: Exploratory Data Analysis Dashboard
  - Distributions, mean/median/std, histograms, boxplots
  - Libraries: `pandas`, `matplotlib`, `seaborn`

- [x] Project 2: Gradient Descent from Scratch Visualizer
  - Implement GD manually, animate convergence
  - Libraries: `numpy`, `matplotlib`

- [x] Project 3: Bayesian Probability Simulator
  - Bayes' theorem applied to real scenarios
  - Libraries: `numpy`, `scipy`

---

## 🧠 Key Concepts

| Concept | Why It Matters for AI |
|---|---|
| Probability distributions | Foundation of all ML models |
| Gradient descent | Core optimization in neural networks |
| Bayes' theorem | Probabilistic reasoning, naive Bayes |
| Standard deviation / variance | Feature scaling, model evaluation |
| Linear algebra (vectors/matrices) | Neural network math |
